# vitrine

## Intenção

1. A primeira resposta da Gê não passa de ~10 s: o cérebro acorda enquanto o webhook espera o cliente parar de digitar.
2. O painel se atualiza sozinho a cada 5 s: conversa, lista e números mudam na tela durante a apresentação, sem F5.
3. A Gê entende áudio: o cérebro transcreve com `gpt-4o-mini-transcribe`, ela responde ao que foi dito, e a ficha mostra o selo "áudio".
4. A Gê não inventa preço: um nó `conferir` no grafo compara todo `R$` da fala com os preços da base; na primeira falha ela reescreve, na segunda cai numa fala segura.
5. O painel mostra o custo real de IA por conversa, gravado mensagem a mensagem com o que o cérebro gastou.
6. O login e o painel dizem quem construiu: dv-dev1, com GitHub e LinkedIn.
7. O repositório se apresenta sozinho: README com prints, sem sobras do create-next-app, e o `avaliar` roda no GitHub Actions.
8. O painel dá retorno ao navegar (esqueleto de carregamento) e passa por uma revisão visual.

## Critério de aceite

```bash
cd cerebro && uv run pytest && uv run ruff check .   # /saude, /transcrever exige token, conferir: 1 chamada, reescrita, fala segura
cd cerebro && uv run --env-file .env python -m agente.avaliar   # 6 ok, nenhuma fala com preço fora da base; exit 0
cd web && npm test          # acordar antes da espera, áudio transcrito e reserva "[áudio]", custo gravado
cd web && npm run lint && npx next typegen && npx tsc --noEmit && npm run build
curl -s https://geniai-cerebro.vercel.app/saude                                                         # {"ok":true}
curl -s -o /dev/null -w '%{http_code}\n' -X POST https://geniai-cerebro.vercel.app/transcrever -d '{}' # 401
```

No navegador (`playwright-cli`, login demo em produção):

- uma mudança no banco demo aparece na tela em até 5 s, sem recarregar;
- o cartão "IA por conversa" mostra um valor em US$;
- o rodapé e o login mostram "Desenvolvido por dv-dev1" com os dois links.

No WhatsApp real (ensaio, número de apresentação):

- "oi" é respondido em menos de 10 s;
- um áudio é entendido;
- o encaminhamento aparece no painel sozinho.

## Fora de escopo

- Aviso ao especialista quando a Gê encaminha: WhatsApp do atendente e cartão no painel. Fica para depois. O número de aviso tem que ser ignorado no webhook e não pode ser o mesmo que conversa com a Gê.
- Roteiro escrito da apresentação.
- Reenfileirar quando a Z-API falha no envio; paginação da lista de leads.
- Mais nós no grafo ou RAG: a base cabe no prompt.
